## 📌 Sobre o Projeto

Este repositório contém as resoluções da terceira lista de exercícios práticos da disciplina de **Raciocínio Algorítmico**. 

O objetivo principal destas atividades é consolidar a transição do pensamento lógico abstrato para a codificação estruturada em Python, exercitando a capacidade de quebrar problemas complexos em instruções sequenciais lógicas e eficientes.

### 🧠 Conceitos Desenvolvidos:
- **Entrada e Saída de Dados:** Manipulação de fluxos de informação com `input()` e formatação de strings de saída (`print`).
- **Expressões Aritméticas e Operadores:** Cálculos matemáticos estruturados respeitando a ordem de precedência dos operadores.
- **Tipagem de Variáveis:** Conversão e manipulação correta de tipos de dados primitivos (como inteiros `int`, reais `float` e textos `str`).
- **Resolução Analítica de Problemas:** Tradução de enunciados e regras de negócio textuais em equações e fluxos computacionais executáveis.

## 📂 Estrutura do Repositório

O repositório está organizado com scripts isolados em Python, onde cada arquivo resolve um problema lógico específico proposto na lista de exercícios:

## 📐 O Pilar do Raciocínio Algorítmico

Na Ciência da Computação, o raciocínio algorítmico é a habilidade de projetar passos claros e inequívocos para resolver um problema, independente da linguagem de programação utilizada. Praticar com exercícios estruturados constrói a base necessária para o entendimento futuro de tópicos avançados, como análise de complexidade, estruturas de dados complexas e desenvolvimento de software robusto.
